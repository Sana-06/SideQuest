# SideQuest

**Less scrolling. More living.**

SideQuest is a fullstack web application I'm developing to make planning activities with friends easier and more engaging.

The idea came from a familiar problem: someone suggests doing something in a group chat, everyone agrees, and then nobody actually makes a plan.

SideQuest aims to solve this by giving friends a shared space to suggest activities, organize plans, vote on ideas, and keep track of their experiences. It combines social planning with gamification to make getting together a little more interesting.

## Features

The following features are planned and will be implemented throughout development.

- **Friend Groups:** Create private groups, invite friends, and manage shared activities.
- **SideQuests:** Suggest activities, organize plans, and track their progress from idea to completion.
- **Group Planning:** Vote on activities, schedule events, and manage attendance.
- **I'm Bored:** Generate activity suggestions based on available time, budget, and group preferences.
- **Chaos Mode:** Submit anonymous suggestions and randomly select the group's next activity.
- **Memories:** Save photos, comments, and highlights from completed activities.
- **Achievements:** Track participation, unlock achievements, and view group statistics.
