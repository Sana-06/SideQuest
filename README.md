# 🎮 SideQuest

### Make plans. Make memories. Make life a little less boring.

**Less scrolling. More living.**

SideQuest is a gamified social planning web application designed to help friends turn *"we should do something sometime"* into *"remember when we did that?"*

From spontaneous adventures and group challenges to shared bucket lists and digital memories, SideQuest makes planning activities with friends easier, more engaging, and a little more chaotic.

> Every great memory starts with a side quest.

---

## ✨ About the Project

We've all been there.

Someone suggests an activity in the group chat. Everyone agrees it sounds fun. Nobody makes an actual plan. Three months later, the idea is buried beneath hundreds of messages.

**SideQuest aims to change that.**

Instead of letting great ideas disappear into group chats, SideQuest gives friends a shared space to discover activities, make decisions, plan adventures, and celebrate the memories they create together.

The goal is simple: **make planning almost as fun as the experience itself.**

## 🚀 Features

The following features are part of the planned application and will be implemented incrementally.

### 👥 Friend Groups
- Create private groups and invite friends.
- Manage multiple friend groups from one account.
- Organize shared activities, plans, and bucket lists.
- Keep group content private to its members.

### 🗺️ SideQuests
- Create and suggest activities for your friends.
- Categorize activities by interests, budget, duration, and location.
- Track quests through different stages: `Idea → Planned → Completed`.
- Browse upcoming adventures and revisit completed quests.

### 🗳️ Group Voting & Planning
- Vote on proposed activities.
- Find suitable dates and times.
- RSVP with `Going`, `Maybe`, or `Can't go`.
- Keep everyone's plans organized in a shared calendar.

### 🎲 I'm Bored
Don't know what to do? Let SideQuest decide.

- Set preferences for budget, available time, group size, and activity type.
- Generate suggestions based on your group's interests and saved ideas.
- Accept a quest, reroll, or save it for later.

### 🔥 Chaos Mode
For when democracy becomes exhausting.

- Everyone submits a secret activity suggestion.
- SideQuest randomly selects the group's next adventure.
- Set boundaries for budget, time, and activity categories.
- Accept the challenge or try again.

*Sometimes the best memories start with questionable planning.*

### 📸 Memories
- Save photos and highlights from completed quests.
- Build a shared digital scrapbook.
- Add comments, memorable quotes, and activity ratings.
- Revisit your group's adventures through a timeline.

### 🏆 Achievements & Statistics
Turn ordinary plans into legendary accomplishments.

| Achievement | How to unlock |
|---|---|
| 🌱 Touch Grass | Complete 5 outdoor activities |
| 🗣️ Professional Yapper | Suggest 20 activities |
| 👑 Main Character Energy | Participate in 25 SideQuests |
| 📅 The Planner | Organize 10 completed activities |
| 🎲 Chaos Enthusiast | Complete 5 Chaos Mode challenges |
| 🎉 We Actually Did It | Complete your group's first SideQuest |

Track your group's adventures, favourite activities, and collective progress.

## 🛠️ Tech Stack

SideQuest is planned as a fullstack web application using modern web technologies.

| Layer | Technology |
|---|---|
| Frontend | SvelteKit, TypeScript |
| Styling | Tailwind CSS |
| Backend | Supabase |
| Database | PostgreSQL |
| Authentication | Supabase Auth |
| File Storage | Supabase Storage |
| Authorization | PostgreSQL Row Level Security |
| Unit Testing | Vitest |
| End-to-End Testing | Playwright |
| Deployment | Vercel (planned) |
| Version Control | Git & GitHub |

The architecture will prioritize modularity, maintainability, security, and testability.

## 🧠 Future Possibilities

Beyond the initial release, SideQuest could explore:

- **Personalized recommendations:** Suggest activities based on group preferences and previous adventures.
- **Smarter activity discovery:** Use recommendation algorithms to rank suitable activities.
- **Location-based discovery:** Find interesting activities and places nearby.
- **Calendar integrations:** Connect SideQuest with external calendars.
- **SideQuest Wrapped:** Generate yearly summaries of adventures, memories, and achievements.
- **Seasonal challenges:** Introduce optional themed quests and events.

These are potential future enhancements rather than commitments for the initial release.

## 💡 Project Motivation

SideQuest started with a simple observation: making plans with friends should not be harder than actually doing them.

I wanted to build something that combines my interest in software development with a problem I encounter in everyday life.

As a Computer Science student at the Norwegian University of Science and Technology (NTNU), I'm developing SideQuest as an independent fullstack project to explore modern web technologies, software architecture, databases, testing, and user-centered design.

The project is both an opportunity to develop my technical skills and an attempt to create something people might genuinely enjoy using.

Rather than building another application that encourages endless scrolling, I want to create one that encourages people to close their screens and go make memories.
